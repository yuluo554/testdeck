## 二、真值纪律

1. **真值只存"输入与期望"**：`expect.json` 存每个用例的 run 序列（输入侧）与期望分型 /
   期望 `flaky_score` / 期望 p50/p95 / 期望回归标记（期望侧）。**不得**存 `observed`
   一类"已经算好的观测"——那会让基准退化成"比对两份预答案"，引擎全坏也全绿。
2. **期望值可由输入独立复算**：`bench/` 里的**参照实现**（`bench/refimpl.py`）只读
   `expect.json` 的输入侧独立算出期望值，与生产实现（`src/testdeck/`）逐值对账。
   参照实现**不 import 生产模块**（AST 守门：`bench/refimpl.py` 禁 import `testdeck.*`，
   实现在 `bench/run_all.py:no_production_import_problems`，并有变异验证：
   `tests/test_bench_refimpl.py` 造一个违规样本断言守门报红）。
   **阈值口径**：参照实现从台账里的 `rules_snapshot` 取阈值，**不读** `src/testdeck/rules/`——
   否则"独立复算"就退化成"读同一份配置互相点头"。快照与生产规则是否一致由
   `tests/test_bench_synth.py::test_rules_snapshot_matches_production_rules` 单独断言。
3. **生成器自证**：`gen_runs.py` 每次写出后立即用参照实现复算，不一致即抛错（不让坏真值落盘）。
4. **`--check` 位级一致**：同 `--seed` 重生成 → 与已登记真值逐字节一致；`--check` 只校验不写盘。
5. **模式覆盖下限**（写进 `gen_runs.py` 的生成期断言，不靠抽样）：
   - 每个分型（`stable` / `flaky` / `broken` / `watch`）至少 1 个用例（**锚点集合与全语料各查一遍**）；
   - `missing` 至少 1 个用例、`skip` 至少 1 个用例；
   - flaky 样本的 `transitions` 覆盖 1..5 梯度；
   - 回归边界六种：`ratio` 恰好 1.2 / 略低 / 略高，`delta` 恰好 200ms / 略低 / 略高；
     **且语料里必须同时存在真回归与非回归**（防"只造变慢样本"→ `regression_false == 0`，
     那样 M5 的"不误报"半边无料可测）；
   - **零计数样本**：全 skip/missing 的用例必须落 `watch`（`fail_rate` 是 0/0）；
   - 生成完**逐项断言这些样本真的存在**（"我打算生成"不等于"生成出来了"）。
6. **不得改真值凑引擎**：真值与引擎冲突时，先判定是"谓词写错"还是"引擎与真值同源修正"；
   后者要同时改 `data/README.md` §四口径与决策记录。

## 三、合成数据纪律（与 `data/README.md` §三 同源，此处只列落地形态）

- 假分支白名单：`main`、`feature/synth-*`、`fix/synth-*`；假仓库名：`demo-app` / `demo-lib` / `demo-web`。
- 假 commit：40 位全数字占位串（`0000…0001` 起递增）；假 `ci_run_id`：`1000000000` 起递增。
- 零真实组织名 / 用户名 / 域名 / 路径。
- `started_at` 用固定基准时刻 + 递增分钟数（**不读系统时钟**），保证可重放。

**零字面量门禁**（M3 起生效，M4 加实装，**M5 三个文件全部落地**）：`tests/test_no_rule_literals.py`

## 五、基准口径

| 基准 | 输入 | 判据 | 门槛 | 状态 |
| --- | --- | --- | --- | --- |
| `bench/bench_ingest.py` | D1–D3 真实产物 | 用例数 / 失败数 / skipped 与各框架自身汇总**逐项相等** | 0 差异 | ✅ M1 |
| 同上（性能） | D6 单文件 5 万用例 | `iterparse` 解析耗时 | < 2s（本机实测，CI 只报告不判红） | ✅ M1（实测 0.07s） |
| `bench/bench_flaky.py` | D5 + D7 | 分型与 `flaky_score` 与 `expect.json` 逐值相等 | 0 差异 | ✅ M4 |
| 同上（差异点） | 恒失败 fixture | `broken ∩ flaky == ∅` | 硬断言 | ✅ M4（两份集合求交，独立断言） |
| `bench/bench_slow.py` | D5 + D7 | p50/p95 与参照实现逐值相等；回归边界六种 | 0 差异 | ✅ M5 |
| `bench/bench_export.py` | 确定性合成模型（导出面是纯函数，不碰库） | md 字段集合 == TUI 模型字段集合；两次导出逐字节一致；三种 `--fail-on` 退出码 | 0 差异 | ✅ M5 |

**解析器归属（M1 → M2）**：`bench/bench_ingest.py` 里自带的 `parse_junit_stream`
曾是 M1「数据先行」期的基准侧计数实现。**M2 起该脚本消费生产解析器**
（`testdeck.junit.parse_file`），并**保留**这份基准侧实现作为独立重数通道——
两者零共享代码，`parser_vs_recount` 检查要求它们逐项相等（互为对照：既防生产实现
算错自我一致，也防基准侧实现漂移）。四条通道的分工与 `plan/03` 模块① 一致；
性能门也改为计时**生产解析器**（基准量的是被测对象，不是基准自己的实现）。

**"缺失 ≠ 0"的落地（K24）**：XML 属性没声明不是"声明为 0"。基准侧的
`declared_in_xml` 把未声明字段记为 `None` 并单独对账；生产解析器只做元素重数，
耗时列没声明写 NULL（`suites.time_ms` 因此可空，schema 版本升到 2）。

**零计数样本的 `fail_rate` 记"无定义"而非 `"0"`（M4 修正）**：`data/README.md` §四
「分型降级②（零计数样本）」早已定钉"`n == 0` 时 `fail_rate` 是 0/0、无定义"，
但参照实现（`bench/refimpl.py`）当时把 `fail_rate` 渲染成 `"0"`——`"0"` 与"跑过且
从没失败"（stable）在数值上撞车，正是该条口径要禁的误导。按本节 §二.6「引擎与真值
同源修正」：改参照实现（`fail_rate` 记 `None`）、**重生成** `expect.json`
（436803 → 436804 字节）、并更新 `data/README.md` §四 的措辞；生产 `flaky.py`
（M4 落地）从一开始就按口径记无定义，两边由此对齐。

**分位数与回归的三条硬口径（M5 落地）**：`bench/bench_slow.py` 除了逐值对账，另有三条
**可证伪**的口径断言——①**缺失耗时不补 0**（拿"补 0"的对照实现复算，结论必须不同）；
②**"不可判"返回 `None` 而不是 `False`**（`undefined_base` / `missing_window` 两种都不得
被算成"无回归"）；③**瀑布条整数运算**（`.5` 边界向上取整，不是 `round()` 的银行家舍入）。
这三条都是"判定口径"而不是"顺手算"，所以基准里有独立的检查项，不只靠单元测试。

**导出面为什么可以不碰库（M5）**：字段声明序、渲染可重放、门禁语义全是**纯函数**——
`render_md` / `render_json` 消费一个 dict，`gate_hits` 只读那个 dict。于是
`bench/bench_export.py` 用**确定性合成的模型 dict** 对账（不依赖 SQLite 的版本/环境），
与 `tests/test_export.py` 互为对照：测试钉单元判据，基准给一份可复跑的总账。

**`run_all` 的"未就绪"口径**（M1 补充）：未到里程碑的套件登记为
`not_enabled=true` + `notes`，并**计入退出码 1**。想只跑已就绪的套件拿 0，
必须显式 `--suites ingest`——不允许"默认跑一部分然后报成功"。

**双边门**：每个套件既要"不误报"（干净样本不得被判命中），也要"能检出"
（注入缺陷后必须报未达标）。探活实现 = `bench/run_all.py --probe`：从实算值派生注入值，
重跑同一套 check 并断言**报出差异**；探活打在消费处（基准读结果的那一行），不打定义处。

**退出码三语义**（`bench/run_all.py`）：`0` 全部达标 / `1` 有未达标 / `2` 用法与未知名错误。
"整套件数据缺失"记 `not_enabled=true` + `notes` 声明 + **exit 1**（不冒充通过）。

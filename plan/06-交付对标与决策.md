## 五、风险登记

| 风险 | 影响 | 缓解 | 触发信号 |
| --- | --- | --- | --- |
| 超大 XML 吃内存 | 解析 OOM | 强制 `iterparse` + `clear()`；5 万用例基准 | 基准耗时/内存超线 |
| 框架格式漂移 | 解析错位、统计失真 | 只依赖核心形状；识别失败记 `unknown` 不猜 | fixture 对账出现差异 |
| run 身份缺失（K26） | 没写身份的产物被合并成一个"未标注 run"，跨 run 视图分辨力下降 | 口径与代价登记在 `plan/02` §三 / `plan/03` 模块①；CI 注入身份属性即可分开 | `runs` 行数与预期不符（如三份产物只出一条 run） |
| 用例身份漂移 | 同一测试被拆成多条 | 身份键固定三元组，保留完整参数串；文档说明改名即新用例 | flaky 列表出现"同名的两条" |
| 口径被复制成第二套 | 数值不可复算 | 规则包单点 + 零字面量门禁 | `test_no_rule_literals` 红 |
| 小样本误判 | 2 次 run 就算 flaky | `transitions >= 3` 门槛；不足样本落 `watch` | 短窗口下 flaky 数量异常高 |
| 终端兼容性 | 窄终端错版 | 自适应单栏；`NO_COLOR` 降级 | Pilot 在 80 列下快照差异 |
| 形态退化 | 只剩一棵树 | `F/S/D` 死壳判据 + Pilot 覆盖三视图 | 任一视图无查询即视为未交付（M3 起由 `test_three_views_render_real_query_results` 钉住） |
| 终端兼容性（真机） | 无头 Pilot 过了但真终端错版 | 自适应单栏；`NO_COLOR` 降级；M5 录屏时在真终端复核 | 录屏与 Pilot 渲染不一致 |
| 隐私 | 日志含路径/token | 纯本地、零网络、导出由用户决定去向 | `test_no_network` 红 |
| 依赖缺失 | 用户没装 textual | `tui` 缺依赖 → exit 3 并给安装命令 | 干净环境冒烟 |
| 本机代理污染 pip | 安装失败被误判为包缺陷 | `NO_PROXY="*"` + 镜像；留档写清定性依据 | 干净 venv 首装失败 |
